Information on max size to encrypt

Maximum number of bytes(!) which can be encrypted in one QR code is about 1200. This is a restriction of QR code standard, encryption and encoding overheads.

When you start entering data to "Text to encrypt" field a helper will appear which will show current number of character and bytes entered. "Bytes (characters encoded to UTF-8)" number should not exceed 1200.

For readability of QR code though it is recommended to encrypt about 500-600 characters in one QR code. If more is encoded QR code elements become small and some phones will have hard time reading such QR code.
